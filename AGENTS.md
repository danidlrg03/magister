# Instructions for agents

## Scope control

- Perform only the requested work and the changes strictly necessary to accomplish it.
- Preserve behavior and architecture outside the scope of the request.
- Do not introduce refactoring, cleanup, incidental fixes, dependencies, or services on your own initiative.
- If you discover another issue, report it without modifying it.
- If fulfilling the request requires expanding its scope, explain why and wait for explicit authorization for that expansion.
- Continue autonomously with work that is already authorized.
- Before finishing, review the diff and justify each changed file against the requested objective.
- A question or review request does not authorize modifications.
